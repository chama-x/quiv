# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `quiv` and our community seriously. If you discover a security vulnerability:

1. **Do not open a public GitHub issue.**
2. Please report the issue privately by opening a [GitHub Security Advisory](https://github.com/quiv-knowledge/quiv/security/advisories/new) or contacting the maintainers directly.
3. Include details of the vulnerability, reproduction steps, and potential impact.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
