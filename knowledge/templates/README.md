# Templates Tier (`templates/`)

## Purpose
Full, production-ready project scaffolding and seed starters.

## Templates Available
- `nextjs-pwa/` — Next.js App Router, Serwist / next-pwa, Tailwind CSS, TypeScript, preconfigured for offline-first ERP
- `vite-pwa/` — Vite + React, `@vite-pwa/plugin`, Tailwind CSS, lightweight client-rendered PWA

## Usage
Copy the template structure directly when bootstrapping a new client project or micro-app.
