# `supabase-launch-week`

> **Sustained 5-day release campaign composition to maintain star velocity above Trending thresholds.**

## Problem
Single-day product launches (e.g. one tweet or one Show HN post) experience rapid decay within 48 hours, dropping off GitHub Trending before reaching the Weekly or Monthly leaderboard.

## Solution
Stage 5 distinct, high-impact product drops Monday through Friday. Each day delivers a dedicated release tag, 60fps video demo, technical narrative thread, and community discussion topic.

## Implementation

```
Monday    → Core Foundation & Benchmark Drop (Hacker News Show HN)
Tuesday   → Progressive Disclosure CLI & Search (Dev Twitter/X Flagship)
Wednesday → 5-Tier Architecture Catalog (Reddit Technical Deep Dive)
Thursday  → AI Agent Interoperability (Claude Code & Cursor Demos)
Friday    → Contributor Flywheel & Roadmap Hackathon (Community Celebration)
```

## Constraints
- Do not launch on Fridays for Day 1 (start on Monday or Tuesday).
- Each daily announcement must be a working, testable capability—not an empty teaser.
