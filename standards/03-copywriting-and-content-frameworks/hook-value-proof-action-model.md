# 🎯 The Hook-Value-Proof-Action (HVPA) Content Model

> **The 4-stage psychological sequence engineered to guide developers from initial curiosity to verified conviction and an automatic GitHub star.**

---

## 1. The 4 Stages of the HVPA Model

```
┌────────────────────────────────────────────────────────┐
│ 1. HOOK    → Disrupt assumptions with a bold reality   │
│ 2. VALUE   → Show immediate, self-evident utility       │
│ 3. PROOF   → Back it with benchmarks and architecture   │
│ 4. ACTION  → Clear, frictionless next step (Star / Run)│
└────────────────────────────────────────────────────────┘
```

### Stage 1: The Hook (First 2 Seconds)
Disrupt complacency. Contrast what developers *think* they have to do with what is now possible.
- *Hook*: *"AI coding agents spend 85% of their context window re-reading bloated boilerplates. What if an agent could pull only the exact 200 tokens of architecture it needs in 10ms?"*

### Stage 2: The Value (Seconds 3–5)
Show the immediate code or terminal transformation:
```bash
$ quiv find "offline sync"
✔ Found 3 patterns (Total tokens: 280)
  1. features/offline-sync (IndexedDB + Outbox) [Tier: Feature]
  2. primitives/storage-kv (Key-Value Engine)   [Tier: Primitive]
```

### Stage 3: The Proof (Seconds 5–15)
Provide empirical evidence:
- **Token Benchmark**: `quiv use` uses **240 tokens** vs. raw file loading at **7,800 tokens** ($32.5\times$ reduction).
- **Type Safety**: 100% strict TypeScript types, 0 runtime overhead.
- **Lore-lite Metadata**: Embedded architectural rationale with automated Git trailers.

### Stage 4: The Action (Star / Run)
Provide immediate micro-commitments:
- Primary Action: `bunx quiv list`
- Secondary Action: *"⭐ Star the repository on GitHub to support open-source agent tooling."*

## 2. Terminal Storytelling: Turning CLI Output into Art

A plain terminal dump is boring. An engineered CLI output is a visual product demo:

### Rules for High-Converting CLI Design:
1. **Clean Status Indicators**: Use crisp unicode glyphs (`✔`, `⚡`, `→`, `◆`).
2. **Token & Latency Badges**: Display token count and execution time directly in the output (`[280 tokens | 14ms]`).
3. **Progressive Breadcrumbs**: Clearly illustrate hierarchical relationships (`knowledge > features > offline-sync`).
4. **Color Hierarchy**:
   - Cyan/Blue: Command execution
   - Green: Completed actions
   - Muted/Gray: Metadata, token sizes, and file paths
   - Amber: Warnings and deprecation notices

## 3. High-Converting Call-to-Action (CTA) Formulas

Never beg for stars. Frame stars as community momentum and roadmap voting:

### CTA Formula 1: The Roadmap Participation Anchor
> *"If you want to see built-in MCP server support and direct vector indexing in v2.0, please star the repo — stars help us prioritize open-source milestones!"*

### CTA Formula 2: The Ecosystem Support Anchor
> *"quiv is 100% free, open-source software under the MIT license. If it saves your AI agents tokens and time, give us a ⭐ on GitHub!"*
